# Roadmap — Shared Minds

## Textual Charades (A06) follow-ups
- Accept near-synonym matches (e.g. "kitten" for "cat") using an embedding-similarity threshold or LLM judge
- Multiplayer rooms: humans guess alongside the machine in real time
- Show similarity score on hover or in a legend
- Taller board shape in portrait so guesses don't crowd the center on narrow phones
- Option to keep the clock running while models think (harder mode)

## 100 (A05) follow-ups
- Auto-detect what's playing in streaming apps (needs a browser extension; demo simulates it)
- Activities-based revenue model written up and reflected in the app
- Decide public vs private heat and whether comments count as talking
